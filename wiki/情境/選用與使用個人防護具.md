# 選用與使用個人防護具

## 什麼時候會遇到

每天上工前。依作業的危害不同，要戴的防護具也不同。

## 雇主要做到的 [職業安全衛生設施規則 §277](../../raw/職業安全衛生設施規則.md#第-277-條第十一章防護具)

- 保持清潔，必要時消毒
- 經常檢查、保持性能，不用時妥善保存
- 數量要足夠；個人使用的防護具，要和作業勞工人數相同或以上，**以個人專用為原則**

## 依危害選擇防護具

| 危害 | 防護具 | 條號 |
|---|---|---|
| 物體飛落、飛散 | 安全帽 | [職業安全衛生設施規則 §280](../../raw/職業安全衛生設施規則.md#第-280-條第十一章防護具) |
| 2 公尺以上高處 | 安全帶、安全帽 | [職業安全衛生設施規則 §281](../../raw/職業安全衛生設施規則.md#第-281-條第十一章防護具) |
| 腐蝕性、毒性物質的搬運、使用 | 手套、圍裙、安全鞋、防護眼鏡、防毒口罩、安全面罩等 | [職業安全衛生設施規則 §278](../../raw/職業安全衛生設施規則.md#第-278-條第十一章防護具) |
| 會傷害皮膚或經皮膚吸收的物質 | 不浸透性防護衣、防護手套、防護靴等 | [職業安全衛生設施規則 §288](../../raw/職業安全衛生設施規則.md#第-288-條第十一章防護具) |
| 輸送腐蝕性物質 | 適當的防護具 | [職業安全衛生設施規則 §289](../../raw/職業安全衛生設施規則.md#第-289-條第十一章防護具) |
| 有害氣體、蒸氣、粉塵、高溫、低溫等 | 安全面罩、防塵口罩、防毒面具、防護眼鏡、防護衣等 | [職業安全衛生設施規則 §287](../../raw/職業安全衛生設施規則.md#第-287-條第十一章防護具) |
| 強烈噪音 | 耳塞、耳罩 | [職業安全衛生設施規則 §283](../../raw/職業安全衛生設施規則.md#第-283-條第十一章防護具) |
| 電焊、氣焊 | 安全面罩、防護眼鏡、防護手套 | [職業安全衛生設施規則 §284](../../raw/職業安全衛生設施規則.md#第-284-條第十一章防護具) |
| 運轉中的機械（可能捲入頭髮、衣服）| 適當的衣帽 | [職業安全衛生設施規則 §279](../../raw/職業安全衛生設施規則.md#第-279-條第十一章防護具) |
| 電氣工作 | 電工安全帽、絕緣防護具 | [職業安全衛生設施規則 §290](../../raw/職業安全衛生設施規則.md#第-290-條第十一章防護具) |

## 呼吸防護具

- 使用呼吸防護具時，雇主要指派專人做危害辨識及暴露評估、選擇、使用、維護管理、教育訓練、成效評估，紀錄保存三年；勞工人數 200 人以上要訂定**呼吸防護計畫** [職業安全衛生設施規則 §277-1](../../raw/職業安全衛生設施規則.md#第-277-1-條第十一章防護具)
- 使用**輸氣管面罩**時，要確保供氣正常，**避免用純氧供氣**；用空氣壓縮機供氣時，輸氣管線及接頭要標示種類及用途，相鄰管線的接頭要用不同規格區隔 [職業安全衛生設施規則 §287-1](../../raw/職業安全衛生設施規則.md#第-287-1-條第十一章防護具)

## 特定作業的規定

- 特定化學物質作業：呼吸用防護具、不浸透性防護衣、防護手套、防護鞋、防護眼鏡，數量和同一工作時間的勞工人數相同以上 [特定化學物質危害預防標準 §50](../../raw/特定化學物質危害預防標準.md#第-50-條第五章健康管理及防護措施)
- 有機溶劑作業：防護具數量和作業勞工人數相同以上 [有機溶劑中毒預防規則 §26](../../raw/有機溶劑中毒預防規則.md#第-26-條第四章防護措施)

> [!TIP]
> **補充說明**
>
> 防護具是「最後一道防線」，前提是通風、隔離等工程控制已經做好。另外，防毒面罩（濾罐式）不能用在缺氧環境，進入缺氧場所要用輸氣管面罩或空氣呼吸器。見 [輸氣管面罩](../名詞/輸氣管面罩.md)。
