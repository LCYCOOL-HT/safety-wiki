# 與承攬商共同作業

## 什麼時候會遇到

公司把工程或工作交給承攬商（包商）做，而承攬商的人員和公司員工在同一個工作場所一起作業時，例如歲修、設備維修、管線施工。

## 交付承攬前

- [ ] 事業單位要**事前**就交付承攬的事業實施**風險評估**，把工作環境、危害因素，以及應採取的安全衛生設備及措施告知承攬人 [職業安全衛生法 §26](../../raw/職業安全衛生法.md#第-26-條第三章安全衛生管理)
- [ ] 承攬期間，要讓承攬人依評估結果確實執行 [職業安全衛生法 §26](../../raw/職業安全衛生法.md#第-26-條第三章安全衛生管理)
- [ ] 承攬人再交付再承攬時，也要照同樣規定辦理 [職業安全衛生法 §26](../../raw/職業安全衛生法.md#第-26-條第三章安全衛生管理)

## 共同作業時，原事業單位要做的事 [職業安全衛生法 §27](../../raw/職業安全衛生法.md#第-27-條第三章安全衛生管理)

- [ ] 設置**協議組織**，並指定工作場所負責人，擔任指揮、監督及協調的工作
- [ ] 工作的連繫及調整
- [ ] 工作場所的巡視
- [ ] 相關承攬人安全衛生教育訓練的指導及協助
- [ ] 機械、設備、器具及人員的進場管制
- [ ] 其他為防止職業災害的必要事項

承攬人、再承攬人要配合辦理原事業單位採取的這些措施 [職業安全衛生法 §27](../../raw/職業安全衛生法.md#第-27-條第三章安全衛生管理)。

## 責任歸屬

- 承攬人就承攬部分負本法所定的雇主責任；原事業單位就職業災害補償仍要和承攬人負連帶責任，再承攬者也一樣 [職業安全衛生法 §25](../../raw/職業安全衛生法.md#第-25-條第三章安全衛生管理)
- 原事業單位違反安全衛生規定，導致承攬人所僱勞工發生職業災害時，要和承攬人負連帶賠償責任 [職業安全衛生法 §25](../../raw/職業安全衛生法.md#第-25-條第三章安全衛生管理)

> [!TIP]
> **補充說明**
>
> 新人常見的角色是「陪同承攬商作業」或「管制承攬商進場」。如果看到承攬商人員沒有照公司規定作業（例如沒戴防護具、沒辦工作許可就進槽），要立刻向主管反映。承攬商出事，公司也有連帶責任。
