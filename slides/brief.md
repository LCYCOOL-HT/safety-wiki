## 1. 基本設定

| 項目 | 設定 |
|---|---|
| 名稱 | 化工廠新人工安入門 |
| 讀者 | 剛進化工廠、沒有工安背景的新人 |

## 2. 風格：專業、溫暖，用清楚的教學結構帶領

> 修訂紀錄（G1，使用者決定）：原本的「安安學姊」角色與台詞整個拿掉，不畫角色圖、不放對話框。溫暖感改由版面、用語和學習節奏來呈現。

### 2.1 教學結構（每頁固定順序）

每頁都照同一個順序，讓學員養成閱讀習慣：

1. **位置**：「第 X 章・第 Y 頁／共 15 頁」與章節名稱（延伸頁顯示「延伸學習」）
2. **學習目標**：讀完這頁可以做到什麼
3. **重點**：條列，每點附條號
4. **圖**：把重點整理成一張圖（只有主線頁有）
5. **自我檢查**：一題單選，答完看解說
6. **導覽**：回地圖、上一頁／下一頁、相關延伸頁

### 2.2 用語

- 用「你」稱呼學員，句子短、白話，但不口語化，也不賣萌。
- 頁面上的所有文字都屬於上面 6 個區塊；**不另外加旁白、提示語或建議**，所以不會出現 wiki 依據以外的內容。

### 2.3 視覺

- **色調**：米白底色，搭配珊瑚橘（重點、按鈕）、深青綠（標題、連結），警示用磚紅。整體溫暖但不幼稚。
- **字型**：使用系統內建的中文字型（微軟正黑體、蘋方、Noto Sans TC），不從網路載入。
- **版面**：圓角卡片、留白充足。每頁一個主圖，重點條列在圖的旁邊或下方。
- **深色模式**：不做，固定淺色，自學時比較不會出問題。

## 4. 每頁投影片的格式

| 區塊 | 規定 |
|---|---|
| 標題 | 和 wiki 情境頁同名 |
| 學習目標 | 1 句，「讀完這頁，你可以……」，30 字以內 |
| 重點 | 3～5 點，每點 40 字以內，**每點附條號連結** |
| 圖 | 主線每頁 1 張（流程圖、比較表、層級圖或數字卡）；延伸節點沒有圖 |
| 自我檢查 | 1 題單選、3～4 個選項。點選後顯示對錯、解說（附條號）。**題目、正確答案、解說都要對得到 wiki** |
| 導覽 | 回地圖、上一頁和下一頁（主線）、相關延伸節點 |

- **不記錄**學員的閱讀進度或答題結果。
- 開場頁要放 wiki 首頁的免責聲明。

## 5. 條號連結

- 條號連到 `raw/` 原文。目前專案還沒推上 GitHub，先用**相對路徑**（`../raw/法規.md`）。
- 之後推上 GitHub 時，只要改設定裡的連結前綴，就能換成 GitHub 網址並跳到該條。

## 6. 檢查標準（給 C1～C4 用）

- 所有條號都要在 `raw/` 裡存在；所有重點、圖上數字、自我檢查都要對得到 `source_pack.json`。
- 頁面上不可以有旁白、提示語或建議等 6 個區塊以外的文字（C2 用程式檢查大綱沒有多餘欄位）。
- 字數上限依第 4 節。
- 主線從開場可以依序走到結尾；每一頁都能回到地圖；延伸節點至少有一個主線節點連過去。
- 自動檢查最多退回 3 次；資料不足的頁面自動移除，在 G1 報告。
