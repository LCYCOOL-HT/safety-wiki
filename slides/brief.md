| 項目 | 設定 |

## 2. 風格：專業、溫暖，由學姊一步步帶領

### 2.1 角色：安安學姊（原創角色）

- **設定**：工安課的學姊，戴白色安全帽、穿反光背心，綁短馬尾，表情溫和。名字取自「安全」的「安」。
- **畫法**：自己用 SVG 畫的扁平風格二次元人物（頭像加半身），準備 4 種表情：微笑、提醒、讚美、認真。**不模仿任何現有作品的角色**。
- **出場方式**：每頁一個對話框，放在頁面左下或右下，不擋住重點內容。

### 2.2 學姊的說話方式

- 用「你」稱呼學員，語氣親切、會鼓勵人，但**不嬌嗲、不賣萌**；講到危險的地方會變得認真。
- 每頁台詞 **60 字以內**，負責引導、串場和提醒，例如「這頁很重要，我們慢慢看」「答錯沒關係，看一下解說」。
- **台詞不放法規事實**：數字、期限、要求一律寫在「重點」區並附條號。台詞只能說「重點第 2 點要記住喔」這類話。
- 每頁最多用 1 個表情符號，也可以不用。

### 2.3 視覺

- **色調**：米白底色，搭配珊瑚橘（重點、按鈕）、深青綠（標題、連結），警示用磚紅。整體溫暖但不幼稚。
- **字型**：使用系統內建的中文字型（微軟正黑體、蘋方、Noto Sans TC），不從網路載入。
- **版面**：圓角卡片、留白充足。每頁一個主圖，重點條列在圖的旁邊或下方。
- **深色模式**：不做，固定淺色，自學時比較不會出問題。

- 地圖頁 1 頁（全部節點與連線，可以點擊跳轉）。

## 4. 每頁投影片的格式

| 區塊 | 規定 |
|---|---|
| 標題 | 和 wiki 情境頁同名 |
| 學習目標 | 1 句，「讀完這頁，你可以……」，30 字以內 |
| 重點 | 3～5 點，每點 40 字以內，**每點附條號連結** |
| 圖 | 主線每頁 1 張（流程圖、比較表、層級圖或數字卡）；延伸節點沒有圖 |
| 學姊台詞 | 60 字以內，不放法規事實 |
| 自我檢查 | 1 題單選、3～4 個選項。點選後顯示對錯、解說（附條號）。**題目、正確答案、解說都要對得到 wiki** |
| 導覽 | 回地圖、上一頁和下一頁（主線）、相關延伸節點 |

- **不記錄**學員的閱讀進度或答題結果。
- 開場頁要放 wiki 首頁的免責聲明。

## 5. 條號連結

- 條號連到 `raw/` 原文。目前專案還沒推上 GitHub，先用**相對路徑**（`../raw/法規.md`）。
- 之後推上 GitHub 時，只要改設定裡的連結前綴，就能換成 GitHub 網址並跳到該條。

## 6. 檢查標準（給 C1～C4 用）

- 所有條號都要在 `raw/` 裡存在；所有重點、圖上數字、自我檢查都要對得到 `source_pack.json`。
- 學姊台詞裡不可以出現數字或法規要求（C2 用程式檢查是否含數字，並由獨立審查確認）。
- 字數上限依第 4 節。
- 主線從開場可以依序走到結尾；每一頁都能回到地圖；延伸節點至少有一個主線節點連過去。
- 自動檢查最多退回 3 次；資料不足的頁面自動移除，在 G1 報告。
